# Halloween and Christmas quest events

## Enable an event

Edit `etc/cfg/holiday-events.properties`:

```properties
halloween.enabled=true
christmas.enabled=false
halloween.edition=2026
christmas.edition=2026
```

Restart the server. Either event, or both, can be enabled. Both ship disabled. Missing enable flags default to false; misspelled values fail startup with an error instead of silently enabling content. The new events do not depend on the real-world month.

The server creates the enabled event's home host, festival NPCs, gathering stations and decorations. Supplies are generated by gathering; no administrator needs to spawn inventory items. Disabling a flag and restarting removes that event's spawned content. Saved progress is retained.

Leave the edition unchanged for restarts and temporary closures. Increment it for a fresh annual edition. This resets that event's quest progress, tokens and first-completion reward eligibility when the player next participates. Halloween and Christmas progress are separate and belong to the account.

## Halloween: The Lanterns of Lost Souls

Talk to Jack the Pumpkin King at home (3098, 3512) to visit the Draynor Manor grounds.

1. Start the quest with Jack at the festival.
2. Gather pumpkin pulp from the Harvest pumpkin, bat bones from the Bone lantern, and ghost slime from the Spirit lantern.
3. Mix the Ritual cauldron's three ingredients in the order described by its clues. The order varies between rounds. A wrong choice restarts the mixture without losing supplies.
4. Visit the three ghosts and solve their individual riddles to light their lanterns.
5. Return to Jack to claim the skeleton outfit on the first completion and five Halloween tokens each round.

The grounds include Aggie, ghosts, a flying pumpkin, jack-o-lantern decorations, spooky stocks and the great cauldron. Repeat rounds earn tokens for a skeleton mask (10), witch outfit (30), or ghostly cloak (15).

## Christmas: The Missing Christmas Delivery

Talk to Santa at home (3098, 3508) to visit the winter fair in Falador Park.

1. Start with Santa at the fair.
2. Gather snowballs from the Festival snowman, bell baubles from Bauble supplies, and unfinished toys from Toy supplies.
3. Follow the Festive workbench's assembly instructions to prepare the three gifts. The assembly order varies between rounds.
4. Match each guest's request: the elf wants a toy soldier, Diango wants a toy cat, and the snowman wants a snow globe.
5. Return to Santa to claim the snow-imp outfit on the first completion and five Christmas tokens each round.

The fair includes Santa, an elf, Diango, snowmen, Jack Frost, presents, candy canes, a snowy bush, an evergreen and a festive workbench. Repeat rounds earn tokens for a reindeer hat (10), snow globe (30), or Christmas jumper (15).

## Player conveniences

- `::holiday` opens the two quest journals and event-pouch previews.
- The host offers travel, quest progress, rewards and return-home options.
- No combat or skill requirements. Quest NPCs cannot be damaged.
- Supplies are in an account-owned event pouch, with existing item icons. They cannot be traded, banked, sold, dropped, or lost on death.
- Progress survives logout, death and server restarts. Full inventories do not consume a completed first reward.
- Repeat completion grants tokens, not another free outfit. Tokens are separate for each event.
- Reward items go into the ordinary inventory. No cash, partyhats, rare Santa hats or endgame weapons are awarded.

## Deployment and layout

Deploy the rebuilt server JAR with both `etc/cfg/holiday-events.properties` and `etc/cfg/holiday-events.json`. Players need the new client JAR for the station actions and extra Talk-to options. Existing cache models are reused; no cache archive update is required.

The JSON file contains all event placements. NPC role -1 is a host (`home` selects the home ambassador); -2 is a helper/decorative character; 0, 1 and 2 are the quest guests. Object roles 0, 1 and 2 supply ingredients; 3 is the crafting station; -1 is decoration. Coordinates use plane 0. Preserve one home host, one festival host, three guests and four interactive stations for each event.

The existing legacy seasonal boss/bonus classes are not activated by these switches. This setup supplies the new quest events independently.

Automated verification covers both event flags, progression order, duplicate actions/claims, persistence, existing object definitions, scenery footprints and paths to the event stations/NPCs using server map collision. Server and client tests/builds passed. A live visual/playthrough check remains necessary before opening an event to players.

## Private Halloween rounds

Talking to Jack at home now starts or resumes a private ground-floor manor. Each round chooses one of 18 layouts: the three ghosts are assigned to three separate room anchors, and the three supply types rotate between the existing gathering spots. Jack and the cauldron stay fixed. Selected interior doorways remain open inside the private instance so the rooms are accessible; the public manor is unaffected.

The layout choice is saved with quest progress. Reconnecting from the private manor returns the player home; talk to Jack again to resume the same layout and supplies. A completed round chooses a different layout on replay. Existing eight-field holiday saves are supported and keep their progress. Christmas is unchanged.

This update is server-only. Stop the test world, update the server, run Prepare Test Server.bat, and restart it. Existing holiday enable flags remain intact.
