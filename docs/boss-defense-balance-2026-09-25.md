# Boss defense balance

Defense levels increased 25% (rounded up). Magic defensive rolls increased about 25% through the magic defense bonus, preserving magic attack levels. Immunity-like bonuses of 10,000 or more are unchanged. Attacks, health, and mechanics are unchanged; live top-tier gear testing is still needed to assess AFK behavior.

Includes boss-points roster variants plus explicitly selected custom bosses. Nomad rewards use an independent rare table: 1/100 base chance for one currency item, uniformly selected among that boss's existing currency types. Certificates award 1-25; loose points award 1-2. The usual rare drop-rate bonus applies (up to 1/50 table access), but quantity doubling is capped and repeated loot rolls do not repeat the currency roll. Non-boss currency tables are excluded. Vacated currency slots remain empty via selection_size so other drops retain their original odds, access rates, and quantities. Deploy the rebuilt server JAR with the updated drop/config files together, then restart. No live deployment or gameplay test was performed.

## Validation and scope

- Targeted drop, announcement, and Leviathan tests passed; server JAR rebuilt at `build/libs/Zaryx-Server.jar`.
- Runtime loader validated every drop table. All 63 changed tables preserve non-currency entries, amounts, and effective selection odds against the original configuration.
- The separate global 25k certificate roll is suppressed for these bosses to prevent additional certificates bypassing the cap.
- Equipment effects that generate loose Nomad points are unchanged; the 1-2 loose-point limit applies to the boss reward table.
- Existing unrelated player-claims and export changes were preserved.
